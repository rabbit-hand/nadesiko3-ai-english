## 🌾 What is "Nadesiko3"? (Acknowledgment & Credits)

"Nadesiko3" is an innovative, open-source programming language originally developed with Japanese syntax by **Mr. クジラ飛行机 (Syunpei Kujira)**. Built on top of JavaScript and TypeScript, it enables seamless cross-platform execution across PCs, smartphones, and tablets. 

This repository adapts its powerful core engine so that **it can be fully utilized via English commands**, making its professional automation, batch processing, and AI capabilities highly accessible to English-speaking developers worldwide.

*Please note that this repository is an unofficial extension package. The core language ecosystem is entirely built upon the incredible work of the original [Japanese Programming Language Nadesiko](https://nadesi.com/). To explore the full potential and the latest official updates, we highly recommend visiting the [Official Nadesiko Website](https://nadesi.com/).*
